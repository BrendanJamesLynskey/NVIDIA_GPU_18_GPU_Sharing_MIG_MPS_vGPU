# Sharing the GPU — MIG, MPS, vGPU, and Kubernetes Time-Slicing

Every way NVIDIA lets multiple workloads share one GPU: hardware-partitioned MIG (A100/H100/B200), software-multiplexed MPS, hypervisor-level vGPU (NVIDIA AI Enterprise), and Kubernetes time-slicing via the GPU Operator. Covers isolation guarantees, performance, licensing, and worked multi-tenant patterns. Includes an interactive sharing-mode picker.
